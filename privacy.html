AutoPost - プライバシーポリシー

本プライバシーポリシーはAutoPostに適用されます。

が提供するn8nおよび生成AIを利用したSNS自動投稿ツール「AutoPost」（以下「本ツール」といいます。）は、利用者のプライバシーを重視し、個人情報の適切な取扱いを行うことをお約束します。本プライバシーポリシーは、本ツールが如何なる個人情報を取得し、どのように利用・保護するかについて説明するものです。

第1条（個人情報の定義）

本プライバシーポリシーにおいて「個人情報」とは、以下の情報を指します。

  1. TikTok APIおよびInstagram APIを通じて取得するユーザー識別子（User ID）、アカウント名等の認証情報
  2. 自動投稿のためにユーザーが入力・アップロードする投稿データ（画像、動画、テキスト、プロンプト等）
  3. 本ツール利用時に生成されるアクセストークン、APIキー等の認証認証情報
  4. その他、利用者を直接または間接的に特定できる情報

第2条（個人情報の取得方法）

本ツールは、以下の方法により個人情報を取得します。

  1. 利用者が本ツールに入力する情報（InstagramおよびTikTokのアカウント認証情報）
  2. TikTok APIおよびInstagram APIを経由して取得するユーザーデータ（ユーザーID、投稿ステータス等）
  3. 生成AIプロンプトおよびコンテンツデータ
  4. 本ツール利用時のログデータ（利用日時、操作履歴等）

第3条（個人情報の利用目的）

本ツールが取得した個人情報は、以下の目的でのみ利用します。

  1. InstagramおよびTikTokアカウントへの自動投稿機能の提供
  2. n8nおよびAPI連携の維持・運用
  3. 本ツール利用者への問い合わせ対応およびサポート提供
  4. 本ツールの機能改善、不具合対応、セキュリティ向上
  5. 本ツール利用規約およびプライバシーポリシーの遵守確認
  6. その他、利用者の同意に基づく目的

第4条（個人情報の保管期間）

  1. 取得した個人情報は、本ツールによる自動投稿機能の提供に必要な期間のみ保持します。
  2. 投稿処理の完了後、APIの有効性維持に必要な範囲でアクセストークン等は一定期間保持されることがあります。
  3. 利用者が本ツールの利用を中止した場合、合理的な期間内に個人情報を削除いたします。
  4. 法令に基づき保管が必要とされる情報を除き、保管期間終了後は個人情報を削除またはフォーマットします。

第5条（個人情報の第三者提供）

  1. 本ツールは、法令に基づく場合を除き、利用者の明示的な同意なく個人情報を第三者に提供することはありません。
  2. 以下の場合については、利用者への事前通知またはプライバシーポリシーの記載により同意があるものとします。
    1. n8n、TikTok、Instagramなどのプラットフォーム提供者との必要な連携
    2. 生成AIサービス提供者（OpenAI等）への必要最小限のプロンプト・データ送信
    3. 法令に基づく政府機関・警察等への情報提供
    4. 本ツール提供に必要な技術サポート企業への委託
  3. いかなる場合においても、利用者の個人情報を販売、賃貸、または不適切な目的で第三者と共有することはありません。

第6条（セキュリティ対策）

  1. 本ツールは、個人情報の損失、盗難、改ざん、不正アクセスを防止するため、以下の技術的手段を講じます。
    1. APIキーおよびアクセストークンの暗号化保存
    2. 通信時のSSL/TLS暗号化
    3. アクセス制限およびログ管理
    4. 定期的なセキュリティ監査
  2. ただし、インターネット通信上の絶対的なセキュリティを保証するものではありません。
  3. 利用者は、自己の責任においてパスワード等の認証情報を厳重に管理するものとします。

第7条（利用者の権利）

利用者は、以下の権利を有しています。

  1. 本ツールが保有する自身の個人情報について、開示を請求する権利
  2. 個人情報に誤りがある場合、訂正または削除を請求する権利
  3. 個人情報の処理を拒否する権利
  4. 本ツールの利用を中止し、個人情報の削除を要求する権利

第8条（外部SNS規約の遵守）

  1. 本ツールを通じて取得される個人情報は、TikTok、Instagramの各利用規約およびプライバシーポリシーにも従うものとします。
  2. 本ツール提供者は、外部SNSの規約変更に伴うデータ処理方法の変更について、法的責任を最小限に留めるものとします。

第9条（プライバシーポリシーの変更）

  1. 本プライバシーポリシーは、法令の変更、セキュリティ強化、ビジネス上の必要性により、予告なく変更されることがあります。
  2. 変更内容は、本ツール上に掲示され、掲示時点から効力を有するものとします。
  3. 変更後に本ツールを継続利用した場合、変更内容に同意したものとみなします。

本プライバシーポリシーは、日本法に準拠し、日本の法律により解釈されます。本プライバシーポリシーに関連する紛争については、東京地方裁判所を第一審の管轄裁判所とします。
